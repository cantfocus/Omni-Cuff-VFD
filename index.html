Setup & pairing (iPhone)

▸

The cuff uses Apple's built-in notification service (ANCS) and the phone's Current Time Service. Nothing needs installing on the iPhone; you pair once and iOS reconnects automatically.

1 · Flash the firmware

  1. Build and upload the nicenano environment: pio run -e nicenano -t upload
  2. The cuff advertises as VFD-nRF-UART.

2 · Pair the iPhone

  1. On the iPhone open Settings → Bluetooth. Under Other Devices, tap VFD-nRF-UART (it may be listed as Accessory). If it doesn't appear, connect to it from the free nRF Connect or LightBlue app instead.
  2. Tap Pair on the Bluetooth Pairing Request.
  3. When iOS asks to share your notifications with the device, tap Allow.
  4. Check Settings → Bluetooth → (i) next to VFD-nRF-UART → Share System Notifications is on.

3 · Check it worked

  1. Connect this page with Connect BLE (top right; Chrome or Edge on a computer). The cuff holds two links at once: one for the phone, one for this editor.
  2. Press Status. You want phone 1, secured 1, ancs 1, cts 1 and a time.
  3. Send yourself a text. The console shows an ANCS add … line and the cuff plays the SMS animation.

Meshtastic

Meshtastic messages arrive as normal iOS notifications from the Meshtastic app, so the app must be allowed to send notifications and be connected to your node. The cuff matches the app ID gvh.MeshtasticClient. If a mesh message shows up as kind=other in the console, note the app= value and update kMeshtasticAppId in src/PhoneLink.h.

On the cuff

  • DOWN (short): open the notification list on the newest one and play its title card.
  • In the list: DOWN older, UP newer (wraps around). SELECT replays the incoming animation, RIGHT plays the replay animation, LEFT goes back to idle. No buttons for the TimeOut setting also goes back to idle. other apps aren't listed.
  • DOWN (hold 1 s): display power on/off.
  • Outside the list, any button dismisses a notification on the display. It doesn't answer or decline calls.
  • The rolling clock is part of the idle animation, which you can edit from the Sequences tab (Send to Device → Idle).
  • Notification history is kept in RAM only. It is never written to flash and is cleared on reboot.

Troubleshooting

  • Pairing loops or ancs 0: press Unpair below, then on the iPhone Settings → Bluetooth → (i) → Forget This Device, and pair again.
  • Notifications missing: iOS only forwards notifications it would show you. Focus / Do Not Disturb, per-app notification settings and Show Previews all apply.
  • Clock shows --:--:--: the phone hasn't synced time since boot. Use Sync time, or Set from this computer to test without the phone.
Future idea: an iOS Shortcuts automation can post a notification like WX 72F Sunny to push weather or anything else to the cuff. See docs/ios-notifications.md.

Notification animations

KindAnimationOn device

Each kind has three animations, stored on the cuff in /ancs/, separate from slots 1–20: Incoming plays when the notification arrives (and on SELECT in the list), the Title card plays when you scroll to it in the list, and Replay plays on RIGHT. Edit opens one in the Sequences tab; Save to device there replaces it. Revert deletes the saved copy and goes back to the built-in default. other isn't listed, so it only has an incoming animation, and none by default.

Test values

Used by the display preview in both tabs and by each kind's Test button, which sends ANCS TEST <id> title|message so you can try an animation without a phone. Testing a title card or replay adds the fake notification to the list and opens it there.

Tokens for text actions

{title}Sender, contact or caller name
{message}Message body (up to 200 chars)
{app}App bundle ID, e.g. com.apple.MobileSMS
{kind}call, missed, sms, mesh or other
{time}HH:MM the notification arrived
{now}Current HH:MM
{pos}Position in the notification list (1 = newest)
{count}How many notifications the list has
{x8E}Font glyph by hex code (◆ button next to text fields)

They work in vfd.text, text.scroll and text.flash. Example: {title}: {message}. Outside a notification they are empty. Emoji become ?. Use clock.show to put the rolling clock in any animation.
