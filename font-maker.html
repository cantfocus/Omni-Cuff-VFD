5×7 Font Maker

Glyphs: ASCII 32–255
Bit order: top = bit0
Output: 5 column bytes
Glyphs: click to edit • drag onto another tile to move it there (tiles between shift over) • Shift-drop = swap • Option/Alt-drop = copy
Click / drag to toggle pixels • Shift+drag = erase • Alt+drag = draw
Top row is bit0, bottom row is bit6.
Edits auto-save in your browser (localStorage).
Into the firmware: Download .h/.cpp gives <name>_ascii32_255.h and .cpp. Replace the pair in src/fonts/, then run node tools/gen-preview-fonts.js so the editor preview matches, and rebuild. A new font name also needs an extern line and a gFontList entry in src/main.cpp (the extern order is the font index).
Tips: Prev/Next or ←/→ keys step through codes. 32 is space, 127 is DEL; 128–255 are labeled 0x80–0xFF.
